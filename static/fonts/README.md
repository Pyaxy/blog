# Local fonts

Noto Serif SC and Source Serif 4, variable normal weights 400–700.
Source Sans 3, variable normal weights 400–600, is used for navigation,
article lists, and metadata; Chinese interface text uses system sans-serif fonts.
Downloaded from the official Google Fonts CSS API on 2026-10-27.
The CSS retains the upstream Unicode ranges, so browsers request only
the subsets needed by each page. All three families use SIL Open Font License 1.1;
each family includes its upstream OFL.txt. No external font requests are
needed when browsing the site.

Source CSS request:
https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@400..700&family=Source+Serif+4:wght@400..700&display=swap

https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@400..600&display=swap

The typography follows the serif heading / sans-serif interface hierarchy
observed on https://platform.claude.com/docs/en/home and https://www.anthropic.com/.
The local font families are open-source alternatives, not Anthropic's brand fonts.
