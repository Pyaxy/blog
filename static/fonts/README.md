# Local reading fonts

Noto Serif SC and Source Serif 4, variable normal weights 400–700.
Downloaded from the official Google Fonts CSS API on 2026-10-27.
The CSS retains the upstream Unicode ranges, so browsers request only
the subsets needed by each page. Both fonts use SIL Open Font License 1.1;
each family includes its upstream OFL.txt. No external font requests are
needed when browsing the site.

Source CSS request:
https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@400..700&family=Source+Serif+4:wght@400..700&display=swap
